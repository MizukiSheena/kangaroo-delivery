# 袋鼠接单

面向手机竖屏的 30 秒极速小游戏。左右滑动接住无人机索降的外卖箱，前段快速上手，后段进入四架无人机同时投递的高峰。漏接只中断连击。

## 本地运行

无需安装依赖。在本目录执行 `npm start`，打开 `http://localhost:4173`。手机可使用同一局域网的电脑 IP 与端口访问。

`npm test` 运行测试。部署目录为 `dist/`，可由任意静态服务器托管。

## 操作

- 手机：在游戏画面下方左右拖动；使用相对移动，按下时不会瞬移。
- 电脑：鼠标拖动，或左右方向键 / A、D。
- 右上角可暂停、开关声音；切换后台自动暂停。
- 普通接单 10 分，完美接单 20 分；每 5 连击增加奖励，单次奖励封顶 20 分。
- 游戏结束后显示送达数、完美数、最高连击；最高分保存在当前浏览器本地，以 30 秒奇遇模式独立记录，保留旧模式纪录。

## 结构

- `dist/game-core.mjs`：不依赖 DOM 的游戏状态、移动、调度和计分。
- `dist/game.mjs`：Canvas 画面、触控、键盘、音效与界面。
- `dist/chaos-core.mjs`：独立奇遇随机流、碰撞、护盾和安全落点。
- `dist/chaos-render.mjs`：使用 Canvas 绘制奇遇角色、道具和危险/奖励预警。
- `dist/assets/`：透明角色动作图集与无人机素材。

角色图集约定为 4 列 2 行，按顺序为 idle、runRight1、runRight2、catch、happy、sad、runLeft1、runLeft2。

## 节奏与调度

- 0–5 秒：每 1.2 秒来单，索降 1.15 秒。
- 5–12 秒：每 0.75 秒来单，索降 0.85 秒。
- 12–22 秒：每 0.48 秒来单，索降 0.72 秒。
- 22–30 秒：每 0.32 秒来单，索降 0.65 秒，最多四架无人机同时投递。
- 飞入 0.45 秒，首单在 0.35 秒出发；四个高度层以颜色和编号对应绳索、箱子与落点。
- 切阶段时按实际接箱时间限制相邻落点距离，并保留 0.12 秒移动余量；接箱时间不倒序。离场 0.16 秒后才复用同层。最后一单在结束前完成。
- 挑战时间按真实经过时间计算，物理分步推进；暂停和后台时间不计入。

## 天空奇遇

首 5 秒专心接外卖，随后每局四位客人各来一次，顺序由独立随机种子打乱：

- 墨镜飞行员鸽子：鸟粪红标要躲，撞到最多扣 10 分且中断连击。
- 香蕉小超人：香蕉皮红标要躲；罕见掉落红内裤，明确金标，接到加 50 分。
- 打嗝小龙：金标龙鳞接到加 30 分。
- 迷糊仙女：金标魔法棒接到加 40 分，获得一次护盾；罕见拿错马桶搋子，金标接到加 60 分。
- 护盾自动抵挡一次危险物，保住连击；不影响移动，局末失效。
- 放弃金标宝物不扣分、不打断连击，也不计外卖漏单。奇遇奖励不计入外卖送达数。

奇遇约在 5.8 / 11.6 / 17.4 / 23.2 秒出现，各有轻微随机偏移。出场后 0.95 秒投物、1.75 秒判定、3.65 秒收尾，场上最多一个奇遇物。红标显示叉号和躲避文字，金标显示加号、名称和分值，不只依赖颜色。

游戏预演原有 55 单的确定性路线，但不消耗外卖随机流。危险落点避开触地时刻前后两单之间的整个移动走廊，保留正常接单路线；落点在预警后保持固定。四架无人机使用 260/320/380/440 高度层，奇遇人物使用 195 高度专用飞行带。四位奇遇角色与六种道具均由 Canvas 绘制；袋鼠和无人机仍使用原有 PNG 素材。
